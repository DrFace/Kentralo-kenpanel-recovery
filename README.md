# KenPanel Recovery Suite

> Unified emergency recovery ecosystem: RecoveryOS, Disaster Kit, and Docker Rescue.

## Subsystems

- ecovery-os/ - Minimal bootable rescue environment, network bootloader, and live repair utilities
- disaster-kit/ - Automated snapshot restoration, corrupted database salvage, and offline repair scripts
- docker-rescue/ - Emergency container recovery, broken image re-tagging, and volume data extractor
- docs/ - Disaster recovery procedures and incident runbooks
